# Basketball Legends

## Theme
This website is a fictional organization dedicated to basketball history, iconic players, and specialized training camps. It uses a pure HTML5 structure without any CSS or JavaScript.

## File Organization
- `index.html`: The homepage featuring articles about legendary players.
- `about.html`: Information about the organization, utilizing multiple semantic HTML tags like figure, aside, and details.
- `services.html`: A structured data table showcasing available training camps, durations, and pricing.
- `contact.html`: A functional form allowing users to submit inquiries.
- `assets/`: A directory containing all the media files used across the web pages (player1.jpg, player2.jpg, player3.jpg).

## Challenges Faced
Working strictly with HTML5 meant relying entirely on semantic tags and native browser styling to convey hierarchy and data structure without the visual aid of CSS. Formatting the table effectively and ensuring the form controls were accessible required careful use of labels, fieldsets, and proper table nesting (thead, tbody, tfoot).
